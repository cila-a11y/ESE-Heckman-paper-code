# Code and replication material for the ESE Heckman selection paper

This repository contains supporting R code and summary CSV files for the paper:

**Transformation–Conditioning Heckman-Type Selection Models  
with Extended Skew-Elliptical Errors**  
Roberto Vila, Cecilia Castro, Víctor Leiva, Helton Saulo, Carolina Marchant (2025).

The repository provides the computational material for the extended skew-elliptical (ESE) framework for Heckman-type sample-selection models introduced in the paper. This includes:

- Extended skew-normal (ESN) and extended skew-\(t\) (EST) errors  
- Monte Carlo pipelines and summary tables  
- The empirical application to the classical `Mroz87` dataset  
- A synthetic heavy-tailed example illustrating when ESE models outperform Gaussian/ESN specifications  
- Fully reproducible R scripts and data summaries

---

## 📁 Repository structure

### **R/**
R scripts used for Monte Carlo experiments, synthetic examples, and empirical analysis.

- **`mc_pipeline_all.R`**  
  Main Monte Carlo pipeline: generates scenario-level and aggregated summaries for ESE/ESN/EST Heckman models.

- **`make_bias_table_from_synth.R`**  
  Builds bias and RMSE tables for the synthetic heavy-tailed experiment presented in the paper.

- **`app_mroz87_esn_vs_hn.R`**  
  Empirical analysis comparing the Gaussian Heckman model and the canonical ESN specification on the `Mroz87` dataset, including an exact nesting check and parametric bootstrap.

### **data/**
CSV files containing summary tables generated by the Monte Carlo pipeline.

- **`ALL_summary_scenario_20251114_132248.csv`**  
  Scenario-level Monte Carlo summaries.

- **`ALL_summary_combined_20251114_132248.csv`**  
  Combined summaries across all scenarios.
